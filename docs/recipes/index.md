# Feature Recipes

Use these scaffolds instead of inventing a new page composition. Read the linked
constitutions before adapting a recipe.

| Recipe                      | Use when                                                           |
| --------------------------- | ------------------------------------------------------------------ |
| `page-shell.md`             | Adding a new app route with title, description, and primary action |
| `collection-empty-state.md` | Building a list/collection page that may have no items yet         |
| `validated-form.md`         | Creating a typed form with React Hook Form and Zod                 |
| `dialog-mutation.md`        | Confirming or completing a blocking create/edit/delete action      |
| `url-filtered-table.md`     | Table with shareable filters or view state in the URL              |

Overview at `/` remains the visual reference for primitives. Recipes are the
generation templates for product pages.
